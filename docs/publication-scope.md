# 공개 자료 안내

이 저장소에는 일반화한 앱 소개, 개편 계기, 개선 과정, 별도로 작성한 학습용 예제와 설명용 도식만 포함합니다.

## 포함하지 않은 자료

- 실제 앱 이름, 패키지명, 스토어 주소와 운영 식별자
- 실제 앱 아이콘·로고·스크린샷·콘솔 화면
- 서명 키, 비밀번호, 인증 자료, 로컬 환경 경로와 계정 설정
- 구매 주문·결제 내역과 사용자 거래·영수증 자료
- 배포 APK·AAB와 실제 앱 전체 소스
- 데이터 저장·이관, 암호화·잠금 등 중요한 운영 구현

학습용 코드의 거래와 숫자는 가상의 예시입니다. 원본 앱의 코드나 데이터로 오인하지 않도록 예제 자체에도 표시했습니다.

원본 앱에서 수행한 검증 결과는 작업 설명으로만 요약했습니다. 이 저장소의 예제에 원본 프로젝트의 테스트 통과 결과를 적용한다는 의미가 아닙니다.
